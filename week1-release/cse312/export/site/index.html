Counting means finding \(|S|\)

Every counting question in this course has the same shape: describe the objects as a set \(S\), then find its size \(|S|\). This week’s tools need a few set ideas from the optional review.

Sets vs. sequences. A set \(\{a,b,c\}\) ignores order and repeats: \(\{3,1,2,3,1\} = \{1,2,3\}\). A sequence (tuple) \((a,b,c)\) keeps both: \((1,2) \ne (2,1)\).

\(|S|\) is the number of distinct elements of \(S\). \(|\varnothing| = 0\), but \(|\{\varnothing\}| = 1\).

Set operations

Click elements to move them between \(A\) and \(B\). The universe is \(U=\{1,\dots,8\}\).

Union \(A\cup B\), intersection \(A\cap B\), difference \(A\setminus B\) (in \(A\), not in \(B\)), complement \(A^c = U\setminus A\). De Morgan: \((A\cup B)^c = A^c\cap B^c\) and \((A\cap B)^c = A^c\cup B^c\).

Quick check: what is \(|\{3,1,2,3,1\}|\)?

  • Looks like you counted the repeats. A set has each element once, so \(\{3,1,2,3,1\}\) is the same set as \(\{1,2,3\}\).
Teaching notes
  • The set review is optional, but Section 1 Task 1 depends on it. Ask: “Is \(\varnothing\) the same as \(\{\varnothing\}\)?” A box holding an empty box isn’t empty.
  • Have students move 4 into both sets in the widget and watch \(|A\cup B|\) stop being \(|A|+|B|\). That’s why the sum rule needs “no overlap”.

The sum rule

Sum rule. If you can choose from EITHER one of \(n\) options, OR one of \(m\) options with NO overlap with the previous \(n\), then the number of possible outcomes of the experiment is

\[n + m.\]

As sets: if \(A\cap B=\varnothing\) then \(|A\cup B| = |A|+|B|\).

Counting “lunches”

A lunch order is either one of 6 soups or one of 9 salads. You get one item, not one of each.

Quick check: a lunch order is either one of 6 soups or one of 9 salads. How many lunch orders are possible?

  • Looks like you multiplied. Multiplying counts pairs (a soup and a salad). Here you pick one item: a soup or a salad.
Teaching notes
  • “Or” with no overlap means add; “and then” (a sequence of steps) means multiply. Ask the room which keyword each example has.
  • The overlap button shows what goes wrong: one item appears in both lists, so adding counts it twice. Lecture 3 (inclusion–exclusion) fixes that. This week we only add disjoint pieces.
  • The textbook’s version: a baby outfit is a top or a bottom (3 + 4 = 7), and a real outfit is a top and a bottom (3 · 4 = 12).

The product rule

Product rule. In a sequential process, if there are \(n_1\) choices for the first step, \(n_2\) choices for the second step (given the first choice), …, and \(n_m\) choices for the \(m\)th step (given the previous choices), then the total number of outcomes is

\[n_1 \times n_2 \times \cdots \times n_m.\]

The options at each step can be different sets. What has to stay fixed is how many there are, whatever was chosen earlier.

Binary strings of length \(n\) over \(\{0,1\}\): \(2\cdot 2\cdots 2 = 2^n\).

Cartesian products

Definition. \(S\times T = \{(a,b) : a\in S,\ b\in T\}\), the set of 2-sequences. Order matters: \((a,b)\ne(b,a)\). Choosing a pair is a two-step process, so

\[|S\times T| = |S|\cdot|T| \qquad |A_1\times\cdots\times A_n| = |A_1|\cdot|A_2|\cdots|A_n|.\]

Power sets: \(|2^S| = 2^{|S|}\)

Definition. The power set of \(S\) is the set of all subsets of \(S\), \(\{X : X\subseteq S\}\). The lecture writes it \(2^S\) (another notation is \(\mathcal P(S)\)). For example \(2^{\{\star,\spadesuit\}} = \{\varnothing,\{\star\},\{\spadesuit\},\{\star,\spadesuit\}\}\) and \(2^{\varnothing}=\{\varnothing\}\).

To build a subset of \(S=\{e_1,\dots,e_n\}\), go through the elements and decide in or out: \(n\) steps with 2 choices each.

Click an element to put it in or out of the subset.

Quick check: how many subsets does \(\{a,b,c,d\}\) have?

  • Close. Did you leave out \(\varnothing\) (or the whole set)? Both are subsets.
  • Did you leave out \(\varnothing\) and \(\{a,b,c,d\}\)? Both are subsets of \(\{a,b,c,d\}\).
  • Each element is a step with 2 choices (in or out). Steps multiply, they don’t add.
  • That’s the number of elements. A subset is any choice of in/out for each one.
Teaching notes
  • Stress “given the previous choices”. The count at each step must not depend on which earlier option was picked. Section Task 7 (birthday cake) is built to break that if you go in the obvious order.
  • Ask: “How many subsets does \(\varnothing\) have?” \(2^0 = 1\): just \(\varnothing\). The slide writes \(2^{\varnothing}=\{\varnothing\}\).
  • Ask the room to list \(2^{\{a,b\}}\) before showing it. Students often forget \(\varnothing\) or the whole set.

Lecture 1 · Wed Sept 30 · Reading 1.1.3–1.1.4

Permutations and complements

“How many sequences in \(\{1,2,3\}^3\) have no repeated element?” The first entry has 3 options. The second has 2, though which 2 depends on the first. The third has 1. The sets change but the counts don’t, so the product rule gives \(3\cdot2\cdot1 = 6\).

Factorial

Definition. The number of ways to order the elements of \(S\), where \(|S|=n\) (the permutations of \(S\)), is the factorial

\[n! = n\times(n-1)\times\cdots\times 2\times 1, \qquad 0! = 1.\]

Counting with complements

“How many sequences in \(\{1,2,3\}^3\) have repeating elements?” Call that \(m\), and let \(n\) be the number with no repeats. Every sequence is in exactly one group, so by the sum rule

\[27 = 3^3 = m + n = m + 3! \quad\Longrightarrow\quad m = 27 - 6 = 21.\]

Enumerate it

Quick check: how many sequences in \(\{1,2,3,4\}^4\) have at least one repeated element?

  • That’s the number without repeats, the complement. Subtract it from the total.
  • That’s every sequence. Some of those have no repeats; take them out.
Teaching notes
  • Why \(0! = 1\): there is exactly one way to order nothing, the empty sequence.
  • Complementary counting is just the sum rule rearranged: \(|S| = |U| - |U\setminus S|\). Ask: “Why is counting repeats directly hard?” (Which position repeats, and how many times? Lots of cases.)
  • Have students step the enumerator a few times before pressing “Run all”. The tally only becomes the answer once every case has been checked.

Lecture 1 · Wed Sept 30 · Reading 1.2.1

\(k\)-permutations

“How many sequences of 5 distinct letters from \(\{A,\dots,Z\}\)?” AZURE, BINGO and TANGO count; STEVE and SARAH don’t. The answer is \(26\cdot25\cdot24\cdot23\cdot22 = 7{,}893{,}600\).

Fact (\(k\)-permutations). The number of \(k\)-element sequences of distinct symbols from an \(n\)-element set is

\[P(n,k) = n\times(n-1)\times\cdots\times(n-k+1) = \frac{n!}{(n-k)!}.\]

Enumerate small cases

Pick an alphabet size and a length. The enumerator goes through every string and keeps the ones with distinct letters. Try 26 letters and length 5: that’s more strings than it will check, so it stops early and says so.

Quick check: 10 runners finish a race. How many ways can gold, silver and bronze be awarded?

  • Looks like you let one runner win more than one medal. Each runner finishes once, so the choices shrink: 10, then 9, then 8.
  • Looks like you treated the medals as interchangeable. Gold for Ann and silver for Bo is a different result from the reverse. Does order matter here?
  • The three medals are awarded in sequence, so the counts multiply.
Teaching notes
  • \(P(n,n) = n!\), so permutations are the special case \(k=n\). The \(\frac{n!}{(n-k)!}\) form works at \(k=n\) because \(0!=1\).
  • Students mix up \(n^k\) (repeats allowed) and \(P(n,k)\) (no repeats). The home page widget has an “allow repeated letters” switch that shows both.
  • Lecture 2 picks this up by asking what happens if order doesn’t matter.

Representation matters

“How many ways are there to distribute 5 books among Alice, Bob and Charlie?” Every book goes to one person; anyone may get 0 books.

Click a book to pass it to the next person.

First attempt: a subset per person

Pick Alice’s set of books (\(2^5=32\) options), then Bob’s (32), then Charlie’s (32): \(32^3 = 32{,}768\). That overcounts. The three choices don’t interact, so a book can land with two people or with nobody. After giving a book to Alice, it’s no longer a valid option for Bob, so “32 options” for Bob doesn’t hold.

The clever approach: ask each book

Look at it from each book’s point of view: who gets it? 3 options, for each of 5 books.

Quick check: in how many ways can 4 different books go to 3 people, if anyone may get none?

  • Looks like you asked each person which book they get. Ask each book which person gets it: how many options does one book have?
  • That’s the “subset for each person” count, which includes books given to two people or to nobody.
  • The 4 books and 3 people aren’t two steps of 4 and 3 choices. Each book is a step.
Teaching notes
  • Run the enumerator on the subset triples and point at the counts: 32,768 triples checked, only 243 valid. The rest give some book to two people or to nobody.
  • Ask: “Can you fix the per-person approach?” (Alice picks any subset, Bob picks from what’s left, Charlie gets the rest. Then Bob’s count depends on Alice’s choice, so the plain product rule doesn’t apply. Asking each book avoids all that.)

Check your understanding: Lecture 1

Ten questions on Lecture 1 only: sets, the sum and product rules, power sets, permutations, complements, \(k\)-permutations and representation. Answer without looking back, then use the review links for anything you missed. The score counts first tries only.

  1. Which of these is equal to the set \(\{1,2,3\}\)?

  2. A café’s lunch special is exactly one item: one of 4 soups, one of 3 sandwiches, or one of 5 salads. No item is in two groups. How many specials are there?

    • Looks like you multiplied. That counts meals with one item from each group. The special is one item from one group.

    Three groups with no overlap, so add them (sum rule): \(4 + 3 + 5 = 12\).

  3. 10 students in a club code in Python and 8 code in Java. When can you conclude that exactly 18 club members code in at least one of them?

  4. What is \(\left|\,2^{\{x,y\}}\times\{1,2,3\}\,\right|\)?

    • Looks like you used \(|\{x,y\}| = 2\). The first factor is the power set \(2^{\{x,y\}}\). How many subsets does \(\{x,y\}\) have?
    • For a Cartesian product, multiply the sizes: \(|S\times T| = |S|\cdot|T|\).

    \(|2^{\{x,y\}}| = 2^2 = 4\) subsets, and \(|S\times T| = |S|\cdot|T|\), so \(4\cdot3 = 12\).

  5. Which of these can you not count with the product rule, using the steps in the order given?

  6. 8 runners finish a race. In how many ways can gold, silver and bronze be awarded?

    • Looks like you let one runner win two medals. Each medal goes to a different runner.
    • Looks like you counted groups of 3 winners. Gold, silver and bronze are different, so does order matter here?

    A sequence of 3 distinct runners: \(P(8,3) = 8\cdot7\cdot6 = 336\).

  7. How many 3-letter strings over \(\{A,B,C,D,E\}\) have at least one repeated letter?

    • That’s the number with no repeats. You want the rest of the strings.
    • That’s every string. Take out the ones with no repeated letter.

    Complement: all strings \(5^3 = 125\), no repeats \(5\cdot4\cdot3 = 60\), so \(125 - 60 = 65\).

  8. 4 different prizes go to 6 students, and one student may win several. Which count is right?

  9. In how many ways can 6 different books go to Ana and Ben, if every book goes to one of them and either may get none?

    • That’s a subset for Ana times a subset for Ben, which includes books given to both or to neither.
    • Looks like you asked each person. Ask each book: how many choices does one book have?

    Ask each book: 2 options, 6 times, so \(2^6 = 64\). (Same as choosing Ana’s subset, since Ben gets the rest.)

  10. Someone counts the ways to give 5 books to Alice, Bob and Charlie as \(2^5\cdot2^5\cdot2^5\), a subset for each person. What’s wrong?

Teaching notes
  • Use it as an exit ticket for the last minutes of lecture or a warm-up in section. Have students commit to an answer before anyone presses Check.
  • Questions 3, 5 and 10 are the conceptual ones: “when does the sum rule apply?”, “when does the product rule apply?” and “spot the overcount”. Ask a student to explain the wrong options too.

Section 1: review and sets

Answer each problem on the page, and use the work box for your reasoning. Hints and solutions stay hidden until you ask for them. Section 1 is spread over three pages: this one, basic counting and harder counting.

Review 1: sum rule

If you can choose from EITHER one of \(n\) options, OR one of \(m\) options with NO overlap with the previous \(n\), then the number of possible outcomes of the experiment is ___.

  • That’s the product rule. Here you pick ONE option, from either group.
  1. Two groups that don’t overlap. Are you picking one from each group, or one thing overall?
  1. Every outcome is in exactly one of the two groups, so count each group and add.
  2. \(n + m\)

Review 2: product rule

In a sequential process with \(m\) steps, if there are \(n_1\) choices for the 1st step, \(n_2\) choices for the 2nd step (given the first choice), …, and \(n_m\) choices for the \(m\)th step (given the previous choices), then the total number of outcomes is ___.

  1. Each choice at step 1 can be followed by any of the \(n_2\) choices at step 2. How many pairs is that?
  1. Each of the \(n_1\) first choices pairs with \(n_2\) second choices: \(n_1 n_2\) ways to do two steps. Keep going.
  2. \(n_1\cdot n_2\cdots n_m\)

Review 3: permutations

The number of ways to re-order \(n\) elements is ___.

  • \(n^n\) lets the same element appear twice. A re-ordering uses each element once.
  1. How many elements can go first? Then how many are left for second place?
  1. \(n\) choices for the first position, \(n-1\) for the second, …, 1 for the last.
  2. \(n!\)

Review 4: \(k\)-permutations

The number of ways to choose a sequence of \(k\) distinct elements from a set of \(n\) elements is ___.

  • \(n^k\) allows repeats. The \(k\) elements must be distinct.
  • That counts sets, where order doesn’t matter. A sequence keeps order.
  1. It’s a permutation that stops after \(k\) steps.
  2. Write \(n(n-1)\cdots(n-k+1)\) using factorials.
  1. \(n\) choices, then \(n-1\), …, and the \(k\)th step has \(n-k+1\).
  2. \(P(n,k) = n(n-1)\cdots(n-k+1) = \dfrac{n!}{(n-k)!}\)

Review 5: set difference

Is it always true that \(|A\setminus B| = |A| - |B|\)? Answer yes or no, and explain in your work.

  1. Try tiny sets. What happens if \(B\) has elements that aren’t in \(A\)?
  1. Counterexample: \(A=\{1\}\), \(B=\{2,3\}\). Then \(|A\setminus B| = 1\), but \(|A|-|B| = -1\), and a size can’t be negative.
  2. Only the part of \(B\) inside \(A\) gets removed: \(|A\setminus B| = |A| - |A\cap B|\).
  3. No. It holds exactly when \(B\subseteq A\).
Teaching notes
  • The posted solutions leave the review blanks empty; the answers here are the rules as stated in Lecture 1. Review 5’s explanation is ours.

Task 1a: cardinalities

For each one of the following sets, give its cardinality, i.e., indicate how many elements it contains.

  • \(\{\varnothing\}\) isn’t empty: it holds one thing, the empty set.
  1. Count only the top-level elements: the things separated by commas inside the outermost braces.
  2. \(\varnothing\) is an object too. A box holding an empty box isn’t empty.
  1. \(|A| = 0\): the empty set has no elements.
  2. \(|B| = 1\): its one element is \(\varnothing\).
  3. \(|C| = 1\): its one element is \(\{\varnothing\}\).
  4. \(|A|=0,\ |B|=1,\ |C|=1,\ |D|=2\)

Task 1b: set operations

Let \(S=\{a,b,c\}\) and \(T=\{c,d\}\). Compute \(S\cup T\), \(S\cap T\), \(S\setminus T\), \(2^{S\setminus T}\) and \(S\times T\). (Check yourself against the solution; a set can be written in many orders.)

  1. \(S\setminus T\) keeps what’s in \(S\) but not in \(T\). The power set of a 2-element set has \(2^2\) elements.
  2. \(S\times T\) pairs every element of \(S\) with every element of \(T\). Don’t skip a pair whose two coordinates are the same.
  1. \(S\cup T = \{a,b,c,d\}\) and \(S\cap T = \{c\}\).
  2. \(S\setminus T = \{a,b\}\).
  3. \(2^{S\setminus T} = \{\varnothing, \{a\}, \{b\}, \{a,b\}\}\).
  4. \(S\times T = \{(a,c),(a,d),(b,c),(b,d),(c,c),(c,d)\}\), which has \(3\cdot 2 = 6\) elements.

Task 2a: credit-card numbers

Credit-card numbers are made of 15 decimal digits, and a 16th checksum digit (which is uniquely determined by the first 15 digits). How many credit-card numbers are there?

  • The 16th digit isn’t a free choice: the first 15 decide it. How many options does it really have?
  1. How many digits can you actually choose?
  2. Once the first 15 digits are set, how many options are left for the checksum?
  1. Each of the first 15 digits has 10 options, and the checksum has exactly 1.
  2. \(10^{15}\)

Task 2b: divisors of 1440

How many positive divisors does \(1440 = 2^5\,3^2\,5\) have?

  • Looks like you didn’t allow an exponent of 0. Is \(1 = 2^0 3^0 5^0\) a divisor?
  • Choosing three exponents is three steps, so the counts multiply.
  1. Every divisor looks like \(2^i3^j5^k\). What values can each exponent take?
  2. Don’t forget that an exponent can be 0.
  1. Every positive divisor of 1440 can be written as \(2^i3^j5^k\) with \(i\in\{0,\dots,5\}\), \(j\in\{0,1,2\}\), \(k\in\{0,1\}\), and different triples give different divisors.
  2. Choose \(i\) (6 options), then \(j\) (3), then \(k\) (2).
  3. \(6\cdot3\cdot2 = 36\)

Task 2c: staff photo

How many ways are there to arrange the CSE 312 staff on a line (11 TAs, 2 professors) for a group picture?

  • That keeps TAs and professors in separate blocks. Anyone can stand anywhere.
  • That lets one person stand in two spots.
  1. 13 different people, 13 spots. Fill the spots left to right.
  1. 13 choices for the first spot, 12 for the second, and so on.
  2. \(13!\)

Task 2d: Anup at an end or in the middle

How many ways are there to arrange the CSE 312 staff on a line so that Anup is at one of the ends or exactly in the middle?

  • Close. Count Anup’s allowed spots again: two ends and the middle.
  • After placing Anup, only 12 people are left to arrange.
  • Anup has more than one allowed spot. Multiply by his options.
  1. Place Anup first. Which spots is he allowed in? (The middle of 13 spots is spot 7.)
  1. Anup’s allowed positions are 1, 7 and 13: 3 options.
  2. Arrange the other 12 people in the remaining 12 spots: \(12!\).
  3. \(3\times 12! = 1{,}437{,}004{,}800\)
Teaching notes
  • The first “place the constrained thing first” problem. Ask what happens if you fill spots left to right instead: spot 1’s options depend on whether Anup still has to go somewhere.
  • In 2b, the “steps” don’t have to be physical. Choosing an exponent is a step.

Task 3: weird card game

In how many ways can a pack of fifty-two cards (in four suits of thirteen cards each) be dealt to thirteen players, four to each, so that every player has one card from each of the suits?

  • That orders all 52 cards with no suit rule. Each player must get one card of each suit.
  • That’s the choices for just the first player. The other 12 players still need cards.
  • Dealing the four suits is four steps one after another, so multiply.
  1. Deal one suit at a time instead of one player at a time.
  2. How many ways are there to give the 13 hearts to 13 players, one each?
  1. First deal the hearts, one to each person: \(13!\) ways.
  2. Then the spades, then the diamonds, then the clubs: \(13!\) ways each.
  3. \((13!)^4\)
Teaching notes
  • Dealing player by player also works: \(13^4\cdot12^4\cdots1^4\), which equals \((13!)^4\) (Reading 1.1.3). A good “two methods” check.

Section 1: harder counting

Strategies for this page: glue things that must be together, place the most constrained thing first, count the complement, and split into cases.

Task 4: seating

How many ways are there to seat 10 people, consisting of 5 couples, in a row of 10 seats if …

  • Each couple can sit in two orders, left/right. Did you count that?
  • That’s every seating. Couples must be next to each other.
  • Each of the five couples picks its own order, so that factor of 2 appears five times.
  • Close. When the couple sits together, they can be in two orders.
  • That’s the number of seatings where they are adjacent. Subtract it from the total.
  1. (a) Treat each couple as one unit.
  2. (b) It’s easier to count the seatings where the couple does sit together.
  1. (a) Consider each couple as a unit. Choose one of the \(5!\) permutations of the 5 couples, then for each couple choose one of 2 orders for how they sit (\(2^5\) in total).
  2. (a) \(5!\cdot 2^5 = 3{,}840\).
  3. (b) Complementary counting: there are \(10!\) arrangements in total. In \(9!\cdot 2\) of them the couple is adjacent (treat the couple as a unit, permute the 9 “individuals”, then pick the couple’s order).
  4. (b) Alternative by cases: if A sits at an end, A has 2 choices and B has 8; otherwise A has 8 choices and B has 7. Then \((2\cdot8+8\cdot7)\,8! = 8\cdot 9!\).
  5. (a) \(5!\cdot2^5\)    (b) \(10! - 2\cdot 9! = 8\cdot 9!\)

Task 5: HBCDEFGA

How many ways are there to permute the 8 letters A, B, C, D, E, F, G, H so that A is not at the beginning and H is not at the end?

  • You subtracted the permutations with A first and H last twice. Add them back once.
  • That’s the number of “bad” permutations. Subtract it from the total.
  • “7 choices for the first letter, then …” breaks the product rule: whether H is still available for the end depends on the first choice.
  1. Count the “bad” permutations: A at the beginning, or H at the end.
  2. Some permutations have both. Make sure they’re removed once, not twice.
  1. There are \(8!\) permutations in total. \(7!\) have A at the beginning and \(7!\) have H at the end.
  2. \(6!\) have both, so (inclusion–exclusion) \(2\cdot7! - 6!\) have A at the beginning or H at the end or both.
  3. Complementary counting: subtract those from the total.
  4. \(8! - (2\cdot 7! - 6!) = 30{,}960\)
Teaching notes
  • The official solution uses inclusion–exclusion for two sets, which Lecture 3 covers properly on Mon, Oct 5. Here it’s enough to notice that “both” got subtracted twice.

Task 6: lizards and snakes!

Loudon has three pet lizards, Rango, a gecko named Gordon, and a goanna named Joanna, as well as two small pet snakes, Kaa and Basilisk, but only 4 terrariums to put them in. In how many different ways can he put his 7 pets in these 4 terrariums so that no terrarium has both a snake and a lizard?

  • That covers the case where the snakes share a terrarium. What if they’re in different ones?
  • That covers the case where the snakes are apart. What if they share a terrarium?
  • That ignores the rule about snakes and lizards.
  • How many pets does Loudon really have? Count the lizards and snakes named in the problem.
  1. Place the snakes first. Then the number of options for each lizard depends on one thing: do the snakes share a terrarium?
  2. Split into two cases and add (sum rule).
  1. The problem says “7 pets”, but it names three lizards and two snakes, so there are 5 animals to place. (The official solution counts 3 lizards and 2 snakes.)
  2. Snakes together: 4 choices of terrarium; each of the 3 lizards then has 3 choices: \(4\cdot 3^3\).
  3. Snakes apart: \(4\cdot3 = 12\) ordered pairs of terrariums; each lizard has 2 choices: \(12\cdot 2^3\).
  4. \(4\cdot 3^3 + 12\cdot 2^3 = 204\)

Task 7: birthday cake

A chef is preparing desserts for the week, starting on a Sunday. On each day, only one of five desserts (apple pie, cherry pie, strawberry pie, pineapple pie, and cake) may be served. On Thursday there is a birthday, so cake must be served that day. On no two consecutive days can the chef serve the same dessert. How many dessert menus are there for the week?

  • Going Sunday to Saturday, Wednesday’s options depend on whether Tuesday was cake. Start from the day that’s fixed.
  • Thursday has only one option: cake.
  • Thursday is fixed, so it contributes 1, not 4.
  1. If you start on Sunday, you get stuck on Wednesday. Why?
  2. Start from Thursday and work outward in both directions.
  1. Thursday: 1 choice (cake). Wednesday and Friday: 4 choices each (anything but the day next to them).
  2. Tuesday, given Wednesday: 4. Monday: 4. Sunday: 4. Saturday, given Friday: 4.
  3. \(4\cdot4\cdot4\cdot4\cdot1\cdot4\cdot4 = 4^6 = 4{,}096\)

Task 8: photographs

Suppose that 8 people, including you and a friend, line up for a picture. In how many ways can the photographer organize the line if she wants to have fewer than 2 people between you and your friend?

  • That’s only the case where you’re next to each other. “Fewer than 2” also allows exactly 1 person between you.
  • That’s only the case with exactly one person between you. You can also be adjacent.
  • You and your friend can stand in either order. Did both cases count that?
  1. “Fewer than 2 people between” means 0 or 1. Two cases.
  2. In the 1-between case, pick the person in the middle and glue the three of you into a unit.
  1. Case 1, adjacent: glue you and your friend into a unit. \(7!\) arrangements of the unit and the other 6, times 2 orders inside the unit: \(2\cdot 7!\).
  2. Case 2, one person between: pick that person (6 choices), glue the trio, arrange 5 people plus the unit (\(6!\)), and 2 orders for you and your friend: \(6\cdot 6!\cdot 2\).
  3. The cases don’t overlap, so add.
  4. \((2\cdot 7 + 2\cdot 6)\cdot 6! = 18{,}720\)

Task 9: extended family portrait

A group of \(n\) families, each with \(m\) members, are to be lined up for a photograph. In how many ways can the \(nm\) people be arranged if members of a family must stay together?

  • Every family reorders its own members, so the factor \(m!\) appears once per family.
  • That lets families split up.
  1. Order the families as blocks first.
  2. Then, inside each block, how many ways can that family stand?
  1. Order the families: \(n!\) ways.
  2. Then reorder each family’s members: \(m!\) ways per family, \(n\) families.
  3. \(n!\,(m!)^n\)

Combinations

“How many size-5 subsets of \(\{A,B,\dots,Z\}\)?” \(\{A,Z,U,R,E\}\), \(\{B,I,N,G,O\}\) and \(\{T,A,N,G,O\}\) count; \(\{S,T,E,V\}\) doesn’t (only 4 letters). The difference from \(k\)-permutations: no order. TANGO, OGNAT, ATNGO and NATGO are different sequences, but \(\{T,A,N,G,O\} = \{O,G,N,A,T\}\) is one set.

The idea: a two-step process

Build a sequence of 5 distinct letters in two steps: (1) choose a subset \(S\) of size 5, then (2) choose an ordering of \(S\). Every sequence comes out exactly once, so

???5-letter sets
×
5!orderings of each
=
26!/21!sequences

\[\text{???} = \frac{26!}{21!\,5!} = 65{,}780.\]

Fact (binomial coefficient). The number of subsets of size \(k\) of a set of size \(n\) is

\[\binom{n}{k} = \frac{n!}{k!\,(n-k)!},\]

read “\(n\) choose \(k\)”. These subsets are also called combinations. Notation: \(\binom{S}{k}\) is the set of all \(k\)-element subsets of \(S\), and \(\left|\binom{S}{k}\right| = \binom{|S|}{k}\).

See the grouping

The enumerator lists every sequence of \(k\) distinct letters and files it under the set of letters it uses. Each set should collect exactly \(k!\) sequences.

Symmetry

Fact. \(\displaystyle\binom{n}{k} = \binom{n}{n-k}\).

Algebraic proof: \(\binom{n}{n-k} = \frac{n!}{(n-k)!\,(n-(n-k))!} = \frac{n!}{(n-k)!\,k!} = \binom nk\). This proves it, but it doesn’t explain why.

A different proof: there are two equivalent ways to choose \(k\) out of \(n\) objects (unordered): choose which \(k\) are included, or choose which \(n-k\) are excluded.

Quick check: a kindergartener smears together 3 different colors out of 7 to make a new color. Order doesn’t matter. How many smeared colors are possible?

  • Looks like you counted ordered arrangements (\(P(7,3)\)). Red-then-blue makes the same smear as blue-then-red. Does order matter here?
  • \(7^3\) lets a color be used twice and keeps order. The 3 colors are different and unordered.
  • Check \(k\): you’re choosing 3 colors, so \(\binom 73\).

Quick check: compute \(\binom{100}{98}\) (as a number or an expression).

  • That’s \(100\cdot 99\), the ordered count. Divide by the \(2!\) orderings.
  • \(\binom{100}{98} = \binom{100}{2}\), not \(\binom{100}{1}\).
Teaching notes
  • The key move is dividing out overcounting: \(P(n,k)\) counts each set \(k!\) times. Run the enumerator with \(n=5,k=3\): 60 sequences, 10 sets, 6 each.
  • For \(\binom{100}{98}\), symmetry turns it into \(\binom{100}{2} = 4{,}950\). Ask the room to do it without a calculator.
  • The textbook’s version is “mini rainbows” (ordered, \(P(7,3)=210\)) vs. “smeared colors” (unordered, \(210/3! = 35\)).

As a string in \(\{\uparrow,\rightarrow\}^7\) with exactly three \(\uparrow\)’s and four \(\rightarrow\)’s, for example \((\uparrow,\rightarrow,\uparrow,\rightarrow,\rightarrow,\uparrow,\rightarrow)\).

Stars and bars

“How many solutions \((x_1,\dots,x_k)\) are there with \(x_1,\dots,x_k\ge 0\) and \(\sum_{i=1}^k x_i = n\)?” Example: \(k=3\), \(n=5\): \((0,0,5)\), \((5,0,0)\), \((1,0,4)\), \((2,1,2)\), \((3,1,1)\), \((2,3,0)\), …

Hint from the slide: represent each solution as a binary string. Write \(x_1\) ones, a 0, \(x_2\) ones, a 0, …, then \(x_k\) ones.

\((3,1,1)\mapsto 1110101\), \((2,1,2)\mapsto 1101011\), \((1,0,4)\mapsto 1001111\). Each string has 7 symbols, exactly two of them 0. Every such string decodes back to exactly one solution, so

\[\#\text{sols} = \#\text{strings in }\{0,1\}^7\text{ with exactly two 0s} = \binom72 = 21.\]

In general there are \(n+k-1\) symbols with \(k-1\) zeros. After a change in representation, the problem reduces to counting combinations.

Stars and bars. The number of ways to distribute \(n\) indistinguishable balls into \(k\) distinguishable bins is

\[\binom{n+k-1}{k-1} = \binom{n+k-1}{n}.\]

For \(k\) non-negative integers summing to \(n\): the bins are the \(k\) integers, and the balls are the \(n\) ones that add up to \(n\).

Enumerate the solutions

Quick check from lecture: how many ways can you distribute 32 identical coins among Alex, Barbara, Charlie, Dana and Eve? (Identify the balls, then the bins.)

  • \(5^{32}\) asks each coin who gets it, which treats the coins as different. They’re identical: only how many each person gets matters.
  • Count the bars: 5 bins need \(5-1\) bars, not 5.
  • The string has the 32 stars and the 4 bars: \(32+4\) symbols in all.
  • Exponents count ordered choices from distinct objects. Use stars and bars here.
Teaching notes
  • Ask: “Which are the balls and which are the bins?” Balls are what’s identical (coins, ones); bins are what’s distinguishable (people, variables).
  • In the widget, set a bin to 0 and watch two bars become adjacent. Empty bins are allowed here.
  • Problem Set 1 asks about a variation of this formula. This page only covers the lecture’s version, where every \(x_i \ge 0\).

Lecture 2 · Fri Oct 2 · Reading 1.2.3

Anagrams and multinomial coefficients

“How many ways to re-arrange the letters in the word SEATTLE?” (STALEET, TEALEST, LASTTEE, …) Guess: \(7!\). Correct? No! Swapping the two T’s gives SEATTLE again, and so does swapping the two E’s. Those were counted as separate permutations but give the same word.

Step through the count

\[\binom72\times\binom52\times3\times2\times1 = \frac{7!}{2!\,5!}\times\frac{5!}{2!\,3!}\times3! = \frac{7!}{2!\,2!} = 1260.\]

Another interpretation: arrange the 7 letters as if they were distinct, then divide by \(2!\) for the duplicate T’s and by \(2!\) again for the duplicate E’s.

Multinomial coefficients. If we have \(k\) types of objects (\(n\) total), with \(n_1\) of the first type, \(n_2\) of the second, …, and \(n_k\) of the \(k\)th, then the number of orderings possible is

\[\binom{n}{n_1,n_2,\dots,n_k} = \frac{n!}{n_1!\,n_2!\cdots n_k!}.\]

“Godoggy”: \(n=7\) letters, \(k=4\) types \(\{G,O,D,Y\}\), \(n_1=3,n_2=2,n_3=1,n_4=1\), so \(\frac{7!}{3!\,2!\,1!\,1!} = \binom{7}{3,2,1,1}\).

Enumerate anagrams

Type a word of up to 8 letters. The enumerator goes through all \(n!\) orderings of its letters (as if they were distinct) and counts the different words produced.

Quick check: how many ways can you arrange the letters in “GODOGGY”?

  • \(7!\) treats the three G’s (and two O’s) as different letters. Swapping two G’s gives the same word.
  • You divided out the G’s. The two O’s are also duplicates.
  • You divided out the O’s. The three G’s are duplicates too.
  • Each group of \(n_i\) identical letters was counted \(n_i!\) times, so divide by factorials.
Teaching notes
  • Step through the SEATTLE count: the running product isn’t the answer until every letter has a spot. Ask “why \(\binom52\) for the E’s and not \(\binom72\)?” (Two spots are already taken by T’s.)
  • Placing the letters in a different order (E’s first, then T’s, …) gives the same product. The bottom numbers of a multinomial can go in any order, but they must add up to the top.
  • Problem Set 1 has word-arrangement questions. This page uses only the lecture’s words (SEATTLE, Godoggy) and the textbook’s.

Lecture 2 · Fri Oct 2 · Reading 1.3.1

The binomial theorem

\[(x+y)^2 = (x+y)(x+y) = xx + xy + yx + yy = x^2 + 2xy + y^2.\]

Each term of \((x+y)^n = (x+y)\cdots(x+y)\) is made by picking \(x\) or \(y\) from each of the \(n\) copies, so it has the form \(x^ky^{n-k}\). How many times do we get \(x^ky^{n-k}\)? As many as there are ways to choose which \(k\) of the \(n\) copies give \(x\) (the other \(n-k\) give \(y\)): \(\binom nk = \binom{n}{n-k}\).

Click a column to highlight its products.

Binomial theorem. Let \(x,y\in\mathbb R\) and \(n\in\mathbb N\) a positive integer. Then

\[(x+y)^n = \sum_{k=0}^{n}\binom nk x^ky^{n-k}.\]

Many properties of sums of binomial coefficients follow from plugging in values of \(x\) and \(y\). With \(x=y=1\): \(\displaystyle\sum_{k=0}^n\binom nk = 2^n\).

Poll from lecture: what is the coefficient of \(xy^3\) in \((x+y)^4\)?

  • \(4^3\) counts ordered choices with repeats. You want the number of ways to choose which one copy gives the \(x\).
  • 3 is the exponent of \(y\), not the coefficient. Count the products \(xyyy, yxyy, \dots\)
  • Several different products (\(xyyy\), \(yxyy\), …) all simplify to \(xy^3\). Count them all.
  • 16 is the total number of products, \(2^4\). Only some of them have exactly one \(x\).

Quick check: what is \(\binom70+\binom71+\cdots+\binom77\)?

  • Plug \(x=y=1\) into the binomial theorem: \((1+1)^7\).
  • There are 8 terms, and they aren’t all 1. Use the binomial theorem with \(x=y=1\).
Teaching notes
  • Poll options from the slides: 4, \(\binom41\), \(\binom43\), 3. Both \(\binom41\) and \(\binom43\) equal 4, which is symmetry again.
  • The last slide sums up the week: \(k\)-sequences \(n^k\) (product rule), \(k\)-permutations \(\frac{n!}{(n-k)!}\) (no repetition), \(k\)-combinations \(\binom nk = \frac{n!}{k!(n-k)!}\) (no repetition, no order).
  • Pascal’s identity \(\binom nk = \binom{n-1}{k-1}+\binom{n-1}k\) is on the slide, marked “next lecture”. It isn’t covered here.

Check your understanding: Lecture 2

Ten questions on Lecture 2 only: combinations, symmetry, paths, stars and bars, multinomials and the binomial theorem. The score counts first tries only.

  1. A club of 10 people chooses a 3-person committee. How many committees are possible?

    • Looks like you counted ordered arrangements. A committee has no first or second member. Does order matter here?
    • That allows the same person to be picked more than once, and keeps order.

    Unordered, no repeats: \(\binom{10}{3} = \frac{10\cdot9\cdot8}{3!} = 120\).

  2. From 20 students, which of these is counted by \(\binom{20}{3}\)?

  3. Which of these is equal to \(\binom{12}{5}\)?

  4. A robot takes 6 unit steps, each one either up or right, and ends 4 to the right of and 2 above where it started. How many different routes can it take?

    • \(2^6\) counts every up/right string of length 6, including ones that end in the wrong place.
    • Looks like you treated the two up-steps as different. Swapping them gives the same route. Does order among the ups matter?
    • \(6!\) treats all six steps as different. All ups look alike, and so do all rights.

    A route is a string of 6 arrows with exactly 2 ups. Choose which 2 of the 6 steps are up: \(\binom62 = 15\).

  5. In how many ways can 10 identical cookies be given to 4 children, if a child may get none?

    • \(4^{10}\) asks each cookie who gets it, as if the cookies were different. They’re identical.
    • 4 children need \(4-1 = 3\) bars, not 4.
    • The string has 10 stars and 3 bars: 13 symbols, not 10.
    • Check the length: \(n+k-1 = 10+4-1\) symbols, of which \(k-1\) are bars.

    Stars and bars with \(n=10\) balls and \(k=4\) bins: \(\binom{10+4-1}{4-1} = \binom{13}{3} = 286\).

  6. How many solutions \((x_1,x_2,x_3)\) in non-negative integers does \(x_1+x_2+x_3 = 4\) have?

    • 3 variables need 2 dividers (zeros), not 3.
    • The binary string has 4 ones and 2 zeros: length 6.
    • \(3^4\) gives each of the 4 units its own label. The units are identical; only the totals matter.

    Strings of four 1s and two 0s: \(\binom{6}{2} = 15\).

  7. How many different words can be made by rearranging the letters of BANANA?

    • \(6!\) treats the three A’s as different letters. Swapping two A’s gives the same word.
    • You divided out the A’s. The two N’s are duplicates too.
    • You divided out the N’s. The three A’s are duplicates too.

    6 letters: 3 A’s, 2 N’s, 1 B. \(\binom{6}{3,2,1} = \frac{6!}{3!\,2!\,1!} = 60\).

  8. Why is \(7!\) not the number of rearrangements of SEATTLE?

  9. What is the coefficient of \(x^2y^3\) in \((x+y)^5\)?

    • Many different products (\(xxyyy\), \(xyxyy\), …) all simplify to \(x^2y^3\). Count them.
    • 32 is the total number of products, \(2^5\). Only some have exactly two \(x\)’s.
    • You picked the two \(x\)-copies in order. Which two copies give \(x\) is a set, not a sequence.

    Choose which 2 of the 5 copies of \((x+y)\) give \(x\): \(\binom52 = 10\).

  10. What is \(\displaystyle\sum_{k=0}^{6}\binom6k\)?

    • Plug \(x=y=1\) into the binomial theorem: \((1+1)^6\), not \(6^2\).
    • There are 7 terms, but they aren’t all 1.

    Binomial theorem with \(x=y=1\): \((1+1)^6 = 2^6 = 64\). Also: it counts all subsets of a 6-element set, grouped by size.

1.1.2: flamingos

Flamingos Fanny and Freddy have three offspring: Happy, Glee, and Joy. These five flamingos are to be distributed to seven different zoos so that no zoo gets both a parent and a child. It is not required that every zoo gets a flamingo. In how many different ways can this be done?

  • That’s only the case where the parents share a zoo.
  • That’s only the case where the parents are in different zoos.
  • That ignores the parent/child rule.
  1. Same idea as the lizards and snakes: place the parents first, and split on whether they share a zoo.
  1. Parents together: 7 zoos for them, then each child has 6 zoos: \(7\cdot6^3\).
  2. Parents apart: \(7\cdot6\) ways, then each child has 5 zoos: \(7\cdot6\cdot5^3\).
  3. \(7\cdot6^3 + 7\cdot6\cdot5^3 = 6{,}762\)

1.1.5 exercise 1: A and B apart

6 people want to line up in a row for a picture, but two of them, A and B, refuse to sit next to each other. How many ways can they sit in a row?

  • 240 is the number where A and B are together. Subtract from all \(6!\).
  • When A and B sit together, they can be AB or BA.
  1. Complement: glue A and B together, count, and subtract from \(6!\).
  1. Together: treat AB as one unit: \(5!\) orders, times 2 for AB/BA: 240.
  2. Or by cases: A at an end (\(2\cdot4\cdot4!\)) or in the middle (\(4\cdot3\cdot4!\)).
  3. \(6! - 2\cdot5! = 480\)

1.2.1: professors between TAs

We have 13 chairs in a row, to seat 9 TAs and Professors Sunny, Rainy, Windy, and Cloudy. How many seatings have every professor with a TA immediately to their left and right?

  • The professors are different people, so which professor sits in which gap matters.
  • A professor at either end has no TA on one side. Only the gaps between TAs work.
  1. Line up the TAs first. Where can a professor go so they have a TA on both sides?
  2. There are 8 gaps between 9 TAs. At most one professor per gap.
  1. Order the 9 TAs: \(9!\).
  2. Choose gaps for the 4 professors, in order, from the 8 inner gaps: \(P(8,4)\).
  3. \(9!\cdot P(8,4) = 609{,}638{,}400\)

1.2.2: escape room pairs

6 AI professors and 7 theory professors take part in an escape room. 4 AI professors and 4 theory professors are chosen and divided into 4 pairs (one AI professor with one theory professor per pair). How many pairings are possible?

  • After picking the 8 professors you still have to match them up.
  • Ordering both groups counts each pairing \(4!\) times. Order the pairs only once.
  1. Choose who plays, then match them up.
  2. For the first theory professor, how many AI partners are possible? The second?
  1. Choose 4 of 6 AI professors and 4 of 7 theory professors: \(\binom64\binom74\).
  2. Match: the first theory professor has 4 choices of partner, the next 3, …: \(4!\).
  3. \(\binom64\binom74\cdot4! = 12{,}600\)

1.2.3: BABYYYBAY

How many ways can you rearrange the letters of “BABYYYBAY” (3 B’s, 2 A’s, 4 Y’s)?

  • \(9!\) treats the repeated letters as different.
  1. Choose where the B’s go, then the A’s among the remaining spots.
  1. \(\binom93\) spots for the B’s, \(\binom62\) for the A’s, \(\binom44=1\) for the Y’s.
  2. \(\binom{9}{3,2,4} = \frac{9!}{3!\,2!\,4!} = 1{,}260\)

1.2.4: students to professors

There are 20 students and 4 professors. The professors only care how many students they get, not which ones. With no restrictions, how many ways can the students be assigned to professors?

  • \(4^{20}\) tracks which students each professor gets. Here only the numbers matter.
  • 4 professors need 3 bars, so the string has \(20+3\) symbols.
  1. Balls: students (indistinguishable here). Bins: professors.
  1. 20 stars and 3 bars.
  2. \(\binom{23}{3} = \binom{23}{20} = 1{,}771\)

1.2.5 exercise 3: die rolls

If we roll a fair 3-sided die 11 times, what is the number of ways that we can get 4 1’s, 5 2’s, and 2 3’s?

  • That’s every sequence of 11 rolls. Only those with exactly four 1’s, five 2’s and two 3’s count.
  1. The outcome is a sequence like 11112222233. How many orderings of those digits are there?
  1. Count orderings of 11112222233.
  2. \(\binom{11}{4,5,2} = \frac{11!}{4!\,5!\,2!} = 6{,}930\)

1.2.5 exercise 4: phone numbers

How many 7-digit phone numbers are such that the digits are (a) strictly increasing (e.g. 014-5689), and (b) monotone increasing, so digits can stay the same or go up (e.g. 011-5566)?

  • Once you pick the 7 digits, there’s only one increasing order. Don’t count the orderings.
  • The counter goes from 0 to 9, so it needs 9 bars, not 10.
  1. (a) Choosing which 7 digits appear decides the number.
  2. (b) Use 7 stars for the digits and bars to move a counter from 0 up to 9.
  1. (a) Choose 7 of the 10 digits; they can only go in increasing order: \(\binom{10}{7}\).
  2. (b) Bijection with arrangements of 7 stars and 9 bars: start a counter at 0; a bar adds 1, a star writes the current digit. 011-5566 is \(*|**||||**|**|||\).
  3. (a) \(\binom{10}{7} = 120\)    (b) \(\binom{16}{7} = 11{,}440\)

1.3.1: a big coefficient

Calculate the coefficient of \(a^{45}b^{14}\) in the expansion of \((4a^3 - 5b^2)^{22}\). Give an exact integer or an exact expression; it’s large and negative.

  • Check the sign: \(y = -5b^2\) is raised to an odd power.
  • The 4 and the −5 get raised to powers too.
  • \(a^{45}\) comes from \((a^3)^{15}\), so \(k = 15\), not 45.
  1. Let \(x = 4a^3\) and \(y = -5b^2\). Which power of \(x\) gives \(a^{45}\)?
  2. You need \(x^{15}y^{7}\).
  1. \(x^{15}\) gives \(a^{45}\) and \(y^7\) gives \(b^{14}\), so the term is \(\binom{22}{15}x^{15}y^7\).
  2. \(\binom{22}{15}(4a^3)^{15}(-5b^2)^7 = -\binom{22}{15}4^{15}5^7a^{45}b^{14}\).
  3. \(-\binom{22}{15}\,4^{15}\,5^{7} = -14{,}306{,}267{,}627{,}520{,}000{,}000\)

Week 1 cheat sheet

Sum rule

Disjoint options: \(|A\cup B| = |A|+|B|\) when \(A\cap B=\varnothing\).

Complement: \(|S| = |U| - |U\setminus S|\).

Product rule

\(n_1\cdot n_2\cdots n_m\), where \(n_i\) is the number of choices given the earlier ones (it can’t depend on which ones were made).

\(|A_1\times\cdots\times A_n| = |A_1|\cdots|A_n|\) · \(|2^S| = 2^{|S|}\)

The three basic counts

\(k\)-sequences over \(n\) symbols\(n^k\)
\(k\)-permutations (no repeats)\(P(n,k)=\frac{n!}{(n-k)!}\)
\(k\)-combinations (no repeats, no order)\(\binom nk=\frac{n!}{k!(n-k)!}\)
Orderings of \(n\) items\(n!\), \(0!=1\)

\(n!\) is huge. Stirling (Lecture 2): \(\sqrt{2\pi}\,n^{n+\frac12}e^{-n} \le n! \le e\,n^{n+\frac12}e^{-n}\).

Lecture 2 tools

\(\binom nk = \binom n{n-k}\), \(\binom n0=\binom nn=1\), \(\binom n1=n\).

Stars and bars: \(n\) identical balls into \(k\) bins: \(\binom{n+k-1}{k-1}\).

Multinomial: \(\binom{n}{n_1,\dots,n_k} = \frac{n!}{n_1!\cdots n_k!}\).

Binomial theorem: \((x+y)^n = \sum_{k=0}^n\binom nk x^ky^{n-k}\), so \(\sum_k\binom nk = 2^n\).

Strategies

  • Choose a representation (books choose people; paths are arrow strings).
  • Glue “must be together” items into blocks.
  • Place the most constrained item first.
  • Split into disjoint cases and add.
  • Count the complement.
  • Divide out overcounting (sets, repeated letters).
  • Check with a second method or a small example.
