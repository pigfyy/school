# Export

- **Frontend:** `../site/` is the export: `index.html`, `app.js`, `base.css`, `course.css`, `fonts.css`, `js/store.js` (owns all persisted state), `js/grader.js`, `js/sim.js` and `fonts/` (IBM Plex) and `vendor/` (KaTeX). Nothing is minified and there's no build step. See `../INTEGRATION.md` §0 for which files own state.
- **`state-inventory.json`:** one entry per stateful item (25 problems, 63 parts, 15 quick checks, 20 quiz questions). Generated by `tests/build-inventory.mjs` from the live DOM. Don't edit it by hand. It contains no answer keys.
