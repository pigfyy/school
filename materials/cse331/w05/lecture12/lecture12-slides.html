JSON

88private static String json(List<String> strings) {
89    List<String> quoted = new ArrayList<String>();
90    for (String s : strings) {
91        quoted.add("\"" + s.replace("\\", "\\\\")
92            .replace("\"", "\\\"").replace("\n", "\\n") + "\"");
93    }
94    return "[" + String.join(", ", quoted) + "]";
95}

Half sheet, question 1 (3 minutes)

  • 1. JavaScript runs one thing at a time
    • Yet while load waits for the server, a click on Post runs post
    • The server is a loop: wait for a request, handle it, wait again
    • What is the browser doing while load waits? When does load go on?

The browser's loop

  • The browser runs a loop, as HttpServer does
    • Wait for an event (a click, a response), then run its callback
  • await cuts a function in two
    • The part before runs now, then hands the thread back
    • The part after runs later, as a callback, when the promise is kept
  • Between the halves, the loop runs what else is ready: a click's post
  • One thing at a time, and still never stuck on the network

await cuts a function in two

load runs to its await, sends its request, and hands the thread back

A click, with the server slow: post runs to its await

The response arrives: the rest of load runs, and draws the list

Then the rest of post. Whichever promise is kept first runs first

One possible run. The events could come in another order: another run

post: send the message

26async function post() {

Who is the client?
