The first time (before any iterations) and for the beginning of each iteration

Rule: while loop - Review
{{ P }}
{{ Inv: I }}

    {{ Inv: I and b }}
    body
    {{ Inv: I }}
}
{{ Inv: I and not b }}
{{ Q }}
The triple {{ P }} while ... {{ Q }} is valid if three checks pass:
{{ P }} implies {{ Inv: I }}.
The triple {{ Inv: I and b }} body {{ Inv: I }} is valid.
{{ Inv: I and not b }} implies {{ Q }}.

Rule: method correctness of an ADT
When the following Hoare Triple is valid:

{{ RI and P(AF(this)) }}
the method's body
{{ RI and Q(AF(this_0), AF(this)) }}

Then the method with precondition (P) and postcondition (Q) is correct.
