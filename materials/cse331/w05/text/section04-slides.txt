--- slide 6 ---
Internally Documenting ADTs – Review
Abstraction Function (AF)
Defines what abstract state the field values represent
Maps field values → the object they represent

Representation Invariants (RI)
Facts about the field values that must always be true
Constructor must always make sure RI is true at runtime
AF only needs to make sense when RI holds
Must ensure that RI always holds outside any method

Loop Invariant – Review
Loop invariant must be true every time at the top of the loop 
The first time (before any iterations) and for the beginning of each iteration
Also true every time at the bottom of the loop
Meaning it’s true immediately after the loop exits
During the body of the loop (during S), it isn’t true

The triple {{ P }} while ... {{ Q }} is valid if three checks pass:
{{ P }} implies {{ Inv: I }}.
The triple {{ Inv: I and b }} body {{ Inv: I }} is valid.
{{ Inv: I and not b }} implies {{ Q }}.

Rule: method correctness of an ADT
When the following Hoare Triple is valid:

{{ RI and P(AF(this)) }}
the method's body
{{ RI and Q(AF(this_0), AF(this)) }}

Then the method with precondition (P) and postcondition (Q) is correct.

// AF: AF(this) = this.snacks[0 .. size] and top = this.snacks[size - 1]
// RI: 0 &lt;= this.size &lt;= this.snacks.length
/**
 * Removes snacks from the top of this until an &quot;Almond Joy&quot; is encountered.
 * The &quot;Almond Joy&quot; is not removed.
 * @modifies this
 * @effects removes all elements above the first occurrence of &quot;Almond Joy&quot;
 *          (from the top); if no &quot;Almond Joy&quot; exists, removes all elements
 * @return true if a &quot;Almond Joy&quot; was encountered, false otherwise
 */
public boolean removeUntil() {
  while (size != 0) {
    String top = this.snacks[size - 1];
    if (top.equals(&quot;Almond Joy&quot;)) {
      return true;
    }
    size--;
  }
  return false;
}
