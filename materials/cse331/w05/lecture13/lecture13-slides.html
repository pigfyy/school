Where does control go from here?

  • A frame: what Java keeps for one call while it runs
    • The method's variables, and the line it is at
  • The call stack: the frames of the calls not yet returned, newest on top
    • A call pushes a frame; a return pops the top one
  • Stand on line 21, g(n);: where does control go next?
    • Line 22 if g returns; out of f if g throws
  • Every call is a place control can come back to, and leave through

Rule: how a throw finds its catch

  • A throw looks for a handler frame by frame down the stack
  • Its own frame first; then, at the line each frame is at:
    • Inside a try with a catch for the exception's class? Control goes to it
    • And the method goes on after the try
    • Otherwise the method ends, and the frame below is next
  • No frame left: Java prints the stack trace, and the program stops

Two questions, answered

  • Where does control go from here?
    • To the next line, or out of the method, through any call
  • How could control have reached this point?
    • At a catch: from every throw under its try
  • The claim at the point has to be true however control got there
    • Make it true at each throw, in the method that throws
