Paths
 The two passing tests ran every branch, but never this combination
 A path through the method is one combination of branches
   quadrant has four, and testing every path finds the mistake
 We do not ask for paths: they multiply

   A loop: a path for every number of times its body can run

                                                                  22
Loop coverage
Definition
A set of tests has loop coverage of a method
if, for every loop in it, some test runs the loop's body zero times,
some test runs it once, and some test runs it more than once.

 Zero times: the code after the loop must be right when it did nothing
 Once: the body must be right on its own
 More than once: what the loop carries from one run to the next

When to stop
A method's tests are enough when there are at least two
and, between them, they have run all an allowed input can reach:
    Every statement
    Both branches of every if
    Every loop's body zero times, once, and more than once
    Every method that calls itself with zero, one, and more than one call

 Until then, the list says which test to write next. Then you may stop.
The second list of James Wilcox and Kevin Zatloukal's "Testing" (2025).

Three things about the list
 Only allowed inputs count, as tip 1 says
   A statement only a disallowed input reaches is not on the list
 The measures nest: loops bring branches, branches bring statements
   Plan for loops and branches, and get statements for free
 In wide use: coverage tools report statement and branch coverage
   Loop coverage you count yourself, as we did for IndexOfTest
   Homework holds a method's tests to the whole list

The floor
 The list says when you may stop, not that you must
 Above the list: how much more depends on what a mistake would cost
   A steering program: every path, every boundary read off the code
   An engineering judgment, on every program you write
 Below the list: no judgment to make
   The list, plus Lecture 4's cases and boundaries
   The least any code you deliver gets, whatever the deadline
That least is the floor. The motto says whose job it is.

   It is large, or does several jobs at once
