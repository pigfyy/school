--- slide 3 ---
Testing Heuristics
• Black-Box Testing: 
• Looking at the spec to test all expected behaviors
• Clear-Box Testing:
• Looking at the code to test all paths
• Boundary Cases:
• Look for inputs on the edge of specific behaviors (i.e. null)
• Exhaustive Testing:
• If there are only a few inputs (&lt;= 10) just test them all!
Notes on Testing Heuristics

--- slide 4 ---
Code Coverage
• Statement coverage: 
• Percentage of statements executed at least once
• Branch Coverage:
• Percentage of branches executed at least once
• Loop Coverage:
•  Every loop/recursive call must be tested 0, 1, and 2+ times
• Path Coverage:
• Percentage of paths through the program executed at least once

JUnit Testing
What is JUnit?
JUnit is a framework for easily developing tests in Java!
JUnit Testing Structure
JUnit tests are split into multiple methods
Each has the @Test annotation at the top
There are other annotations (@Before, @BeforeEach, etc)
Each test method is made up of assertions

public static int removeValue(int[] a, int n, int x) {
  int w = 0;
  for (int r = 0; r &lt; n; r++) {
      if (a[r] != x) {
          a[w] = a[r];
          w++;

  }
  return w;

--- slide 24 ---
Above the floor
Testing up to the floor satisfies the minimum requirements, but it does not guarantee that our code is bug-free.

Testing is more than checking boxes. It's about identifying and reducing the risk of undiscovered bugs.

That's why testing beyond the floor requires engineering judgment.

--- slide 25 ---
Engineering judgement
We must consider:
Where are bugs most likely to be hiding?
What are the consequences if those bugs go undetected?
How much additional testing is worth the time and effort?

The goal isn't to test everything.
It's to reduce the risk of undiscovered bugs to an acceptable level.

@Test
public void testComputeSum() {
    int[] arr1 = new int[0];
    assertEquals(0, computeSum(arr1));

    int[] arr2 = {5};
    assertEquals(5, computeSum(arr2));

    int[] arr3 = {0, 3, 3, -1, 0};
    assertEquals(5, computeSum(arr3));
}

public static int computeSum(int[] arr) {
  if (arr == null) {
    throw new IllegalArgumentException(&quot;&quot;);
  }
  int sum = 0;
  for (int i = 0; i &lt; arr.length; i++) {
    sum += arr[i];
  }
  return sum;
}
