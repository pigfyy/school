Abstract data type
Definition: abstract data type (ADT)
An abstract data type is a type defined by specs for its operations.
The abstract state is how clients should think about the object.

HelpQueue's abstract state: the students waiting, in the order they joined




                                                                             13
Representation
Definition: representation
The representation of an ADT is how it is implemented.
This includes the fields of the class and the code of its methods.
The specification never mentions the representation.

ListQueue's representation: one list of the NetIDs waiting, front first
