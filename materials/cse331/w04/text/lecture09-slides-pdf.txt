The calculator's main was a loop. Seven lines here, and no loop: where is it?

Not a call: the method handle itself, handed to the server as a value

The loop starts inside HttpServer; main returns, and the program keeps running




                                                                                 19
Event-driven
 The loop is inside HttpServer: wait for an event, call handle
 Event-driven: methods called by a loop the program does not own
 A library is code you call; a framework is code that calls you
 HttpServer is a framework: nothing in the file calls handle, yet it runs
   To know when, you read the framework's specification

Servers and browsers
A server is a program that waits for requests
and answers each with a response.
  The guestbook is a server; the browser is one of its users
    The browser relies on what the guestbook promises
    The guestbook can assume nothing about what the browser sends
  The web calls the browser the server's client
    Lecture 2's client can be held to a promise; no browser can be
