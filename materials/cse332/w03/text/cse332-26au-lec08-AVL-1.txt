Dictionary (Map) ADT
• Contents:
   • Sets of key+value pairs
   • Keys must be:
       • Unique (always) and Comparable (for many dictionary implementations)
• Operations:
   • insert(key, value)
       • Adds the (key, value) pair into the dictionary
       • If the key already has a value, overwrite the old value
           • Consequence: Keys cannot be repeated
   • find(key)
       • Returns the value associated with the given key
   • delete(key)
       • Remove the key (and its associated value)

Binary Trees: Some Numbers (Answers)
Recall: height of a tree = longest path from root to leaf (count edges)


For binary tree of height h:
   • max # of leaves:            2h
   • max # of nodes:          2(h + 1) - 1
   • min # of leaves:               1
   • min # of nodes:              h+1

                        For n nodes, we cannot do better than O(log n) height,

AVL Tree
• A Binary Search tree that maintains that the left and right subtrees of
  every node have heights that differ by at most one.
   • height of left subtree and height of right subtree differ by at most 1
   • Not too weak (ensures trees are short)
   • Not too strong (works for any number of nodes)

• Idea of AVL Tree:
   • When you insert/delete nodes, if tree is “out of balance” then modify the tree
   • Modification = “rotation”

Insert Summary
• After a BST insertion, update the heights of the node’s ancestors
• From leaf to root, check if each node is balanced
• If a node is unbalanced then at the deepest unbalanced node:
   • Case LL: If we inserted in the left subtree of the left child then: rotate right
   • Case RR: If we inserted in the right subtree of the right child then: rotate left
   • Case LR: If we inserted into the right subtree of the left child then: rotate left at
     the left child and then rotate right at the root
   • Case RL: If we inserted into the left subtree of the right child then: rotate right at
     the right child and then rotate left at the root
• Done after either reaching the root or applying one of the above cases

                 root.right = insertHelper(key, value, root.right);
        else
                 root.left = insertHelper(key, value, root.left);
        if (isUnbalanced(root))
                 root = rotate(root);
        return root;
}                                                                     54
