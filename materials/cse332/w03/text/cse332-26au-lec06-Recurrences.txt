public static boolean binarySearch(List<Integer> lst, int k){
        return binarySearch(lst, k, 0, lst.size());
}
private static boolean binarySearch(List<Integer> lst, int k, int start, int end){
    if(start == end)
        return false;
    int mid = start + (end-start)/2;
    if(lst.get(mid) == k){
        return true;
    } else if(lst.get(mid) > k){
        return binarySearch(lst, k, start, mid);
    } else{
        return binarySearch(lst, k, mid+1, end);
    }
}

   Coming up with a Recurrence Relation
• Overall structure of a recursive function:
   1. Do some non-recursive “work”
   2. Do one or more recursive calls on some portion of your input
   3. (maybe) Do some more non-recursive “work”
   • (Repeat recursive calls until you reach a base case)
• Recurrence Relation: 𝑇𝑇 𝑛𝑛 = 𝑇𝑇 𝑝𝑝1 + 𝑇𝑇 𝑝𝑝2 + ⋯ + 𝑇𝑇 𝑝𝑝𝑥𝑥 + 𝑓𝑓(𝑛𝑛)
• The time it takes to run the algorithm on an input of size 𝑛𝑛 is:
   • The sum of how long it takes to run the same function on each smaller input

Recursive List Summation Code
public int sum(int[] list){
    return sum_helper(list, 0, list.size);
}
private int sum_helper(int[] list, int low, int high){
    if (low == high){ return 0; }
    if (low == high-1){ return list[low]; }
    int middle = (high+low)/2;
    return sum_helper(list, low, middle) + sum_helper(list, middle, high);
}

Really common recurrences
Should know how to solve recurrences but also recognize some
really common ones:
 T(n) = O(1) + T(n/2)           logarithmic O(log n)
 T(n) = O(1) + 2T(n/2)          linear      O(n)
 T(n) = O(1) + T(n-1)           linear      O(n)
 T(n) = O(n) + T(n-1)           quadratic   O(n2)
 T(n) = O(1) + 2T(n-1)          exponential O(2n)
 T(n) = O(n) + T(n/2)           linear       O(n)
 T(n) = O(n) + 2T(n/2)          loglinear    O(n log n)
