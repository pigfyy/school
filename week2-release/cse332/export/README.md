# Export

- **Frontend:** `../site/` is the export: `index.html`, `app.js`, `fonts.css` + `fonts/` (IBM Plex Sans / Mono), `base.css` (shared house style), `course.css` (this course's widgets), `js/store.js` (owns all persisted state), `js/grader.js`, `js/sim.js` and `vendor/` (KaTeX). Nothing is minified and there's no build step. See `../INTEGRATION.md` §0 for which files own state.
- **`state-inventory.json`:** one entry per stateful item (11 problems, 40 parts, 10 quick checks, 10 quiz questions). Generated by `tests/build-inventory.mjs` from the live DOM. Don't edit it by hand. It contains no answer keys.
